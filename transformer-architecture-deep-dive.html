Demystifying the Transformer Architecture: From Self-Attention to Modern LLMs

Introduction to the 'Attention is All You Need' Paper

The original 'Attention is All You Need' paper by Vaswani et al. radically changed natural language processing by replacing RNNs and LSTMs with self-attention mechanisms. It allowed for massive parallelization and mitigated the vanishing gradient problem in long sequences.

Self-Attention Math (Q, K, V)

The core of the transformer is scaled dot-product attention. Given Queries (Q), Keys (K), and Values (V), the attention output is computed as: Attention(Q, K, V) = softmax(QK^T / sqrt(d_k))V. This allows the model to weigh the importance of different words in a sequence when encoding a particular word.

Multi-Head Attention & Positional Encoding

Multi-head attention projects Q, K, and V into multiple subspaces, computing attention independently, and concatenating the results. Positional encoding uses sinusoidal formulas: PE(pos, 2i) = sin(pos / 10000^(2i/d_model)) and PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model)), injecting order information into the sequence.

Encoder-Decoder Structure

The encoder stack processes the input sequence, while the decoder stack generates the output autoregressively, employing masked self-attention to prevent peeking ahead. Each layer features Layer Normalization and Feed-Forward Networks.

    def __init__(self, embed_size, heads):
        super(SelfAttention, self).__init__()
        self.embed_size = embed_size
        self.heads = heads

BERT vs GPT & Scaling Laws

BERT is an encoder-only model trained on masked language modeling, while GPT is a decoder-only model trained on causal language modeling. Scaling laws indicate that model performance scales predictably with compute, dataset size, and parameter count.
