Mastering Distributed Tracing with OpenTelemetry in Production

Observability Pillars

Modern observability relies on Logs, Metrics, and Traces. A trace represents a single user journey across multiple services, composed of individual spans.

OpenTelemetry Architecture

OpenTelemetry provides a unified API, SDK, and Collector for instrumentation. It standardizes W3C TraceContext propagation across HTTP/gRPC boundaries.

Instrumentation and Sampling

Auto-instrumentation wraps popular libraries, while manual instrumentation allows custom span creation. Sampling is critical: head-based sampling decides at the edge, while tail-based sampling decides at the collector based on outcome (e.g., error spans).


from opentelemetry import trace
tracer = trace.get_tracer(__name__)
with tracer.start_as_current_span("parent_span"):
    with tracer.start_as_current_span("child_span"):
        print("Tracing active")
